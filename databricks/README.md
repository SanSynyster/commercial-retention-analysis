# Databricks Asset Bundle

This folder contains a Databricks Asset Bundle for running the Spark gold-mart pipeline in Databricks.

## What It Runs

Job: `commercial_retention_spark_gold_build`

Task: `build_gold_retention_marts`

The task calls `databricks/notebooks/run_gold_pipeline.py`, which imports the shared production logic from `src/spark_pipeline.py`.

## Required Parameters

| Variable | Purpose |
| --- | --- |
| `clean_transactions_path` | Path to the clean transaction parquet generated by the Python pipeline or uploaded to cloud storage |
| `target_schema` | Schema/database for gold Delta marts |
| `catalog` | Optional Unity Catalog name |
| `write_mode` | Delta write mode, usually `overwrite` |

## Commands

Validate the bundle:

```bash
databricks bundle validate -t dev
```

Deploy:

```bash
databricks bundle deploy -t dev
```

Run:

```bash
databricks bundle run commercial_retention_spark_gold_build -t dev
```

## Azure Account Note

You do not need an Azure account to keep developing and testing the local repository. You need Azure only when you want to create a real Azure Databricks workspace, configure storage, deploy this bundle, and run the job in the cloud.
